# HACKITON'26 — Cinematic 4K Invitation & Hackathon Arena

An ultra-luxury, cinematic web experience designed for **HACKITON'26** (24-Hour National Level Hackathon) at **KPR Institute of Engineering and Technology** presented by the **Department of Information Technology & IEEE (ITS)**.

Built with responsive scaling for **4K UHD (3840 × 2160)** displays down to mobile screens.

---

## ✨ Features & Stages

1. **Stage 1: The Principal's Royal Gold Invitation**
   - Slow cinematic fade-in from pure black.
   - 3D sculpted gold metallic KPR emblem (`Learn Beyond`).
   - Ornate gold bracket badge: `✦ SPECIAL INVITATION ✦`.
   - Chiseled 3D metallic gold typography for **`HACKITON'26`** with animated light shimmer.
   - 4 Domain pillars: `AI`, `CYBERSECURITY`, `SMART INDUSTRY`, `GREEN TECHNOLOGY`.
   - Concentric glowing gold stage rings with perspective depth, vertical light beams, and horizon flare.

2. **Stage 2: Cyberpunk Glitch Transition**
   - Web Audio API synthesized bass drop and cyber static.
   - Chromatic aberration, terminal matrix decryption feed, and RGB split.

3. **Stage 3: 4K Hackathon Arena Showcase**
   - Official branding: KPR Institute, IEEE Student Branch, and IEEE ITS SBC.
   - Distressed cyber brush title **`HACKITON'26`**.
   - Event intel: `OCT 08-09` & `TEAM CAPACITY 2-4 PER TEAM`.
   - 6 Interactive Sci-Fi HUD bracket domain cards (`AI & SMART TECH`, `CYBER SAFETY`, `SMART INDUSTRY`, `OPEN INNOVATION`, `HEALTH TECH`, `GREEN TECH`) with full details modal.
   - Holographic glowing cyber champions trophy with interactive 3D mouse parallax tilt.

   - Command & Coordination console: Student and Faculty coordinators.
   - Registration portal & interactive **`VISIT OFFICIAL WEBSITE`** button with QR code click-to-zoom modal.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python3 -m http.server 8080

# Or using npx serve
npx serve .
```

Open `http://localhost:8080` in your browser.

### URL Query Parameters

- `?nodelay=1` — Skips the black curtain delay and reveals the invitation screen immediately.
- `?stage=hackathon` — Jumps directly to the Cyberpunk Hackathon Arena stage.
